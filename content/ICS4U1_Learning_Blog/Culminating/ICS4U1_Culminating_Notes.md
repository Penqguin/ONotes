# Culminating Assignment Notes: ICS4U1

This document summarizes the work done on the Java culminating project.

## 1. Project Overview
The project was a collaborative effort to build a database-driven management application in Java. It allows users to store, track, and retrieve data persistently using SQLite.

## 2. What Was Accomplished (Chronological Summary)
- **Planning & Setup:**
    - Defined project goals and requirements.
    - Set up the GitHub repository to manage code collaboratively.
    - Configured the development environment, including the SQLite JDBC driver for database connectivity.
- **Architectural Design:**
    - Organized the code into logical packages to keep things clean:
        - `ui`: Designed the visual interface using Java Swing.
        - `model`: Created data classes to represent the objects handled by the app.
        - `util`: Developed helper classes for database management.
- **Development Phase:**
    - Implemented core database functionality (connecting, saving, loading data).
    - Built the user interface components for user interaction.
    - Linked the UI to the database logic to ensure data persistence.
- **Documentation & Cleanup:**
    - Wrote the `README.md` to explain how to compile and run the project.
    - Documented the project requirements in `ICS4U Final Assignment.docx.md`.
    - Finalized the code for submission.

## 3. Technical Highlights
- **Language:** Java
- **Database:** SQLite (via JDBC)
- **Interface:** Java Swing (GUI)
- **Tools:** Git/GitHub for collaboration

## 4. Key Takeaways
- Gained hands-on experience in connecting a Java application to a database.
- Improved skills in designing user-friendly interfaces.
- Learned how to manage a collaborative project using version control.
